# ClipVault 演示视频脚本（5-8 分钟）

> 录制建议：浏览器全屏 + 系统声音，提前关闭无关标签页。每一步先念引导词再操作，操作完停 1 秒。
> 手机演示部分需另一台手机（或用浏览器开发者工具的手机模拟先代替，真机更佳）。

---

## 开场（30 秒）

**念**：大家好，我做的项目是 ClipVault 云剪切板分享系统。它解决的问题是：手机和电脑之间传一段文字、一个链接、一个代码片段，还要安全、可控、阅后即焚。下面我完整演示一遍。

**操作**：打开首页 `http://服务器IP`，停留 2 秒展示界面。

---

## 第一部分：文本分享核心流程（1.5 分钟）

**念**：最核心的功能，粘贴内容，生成分享链接和二维码。

**操作**：
1. 在文本框粘贴一段文字（建议：一段含链接的文字，如「项目文档 https://github.com/xxx 」）
2. 指出选项：内容类型自动识别、有效期 24 小时、访问次数无限制
3. 点击「生成分享链接」
4. **念**：链接和二维码立刻生成，旁边是有效期和次数信息
5. 点击「复制」，新开一个**无痕窗口**粘贴打开 —— **念**：任何设备任何浏览器都能访问，不需要登录
6. 回到原页面，展示「我的分享」历史记录（含销毁令牌说明）

---

## 第二部分：Markdown 与代码高亮（1 分钟）

**念**：系统会自动识别内容类型。比如我贴一段 Markdown。

**操作**：
1. 回到首页，粘贴一段 Markdown（演示用示例见文末附录 A）
2. 点击生成，打开链接 —— 展示渲染后的标题、表格、代码块高亮效果
3. **念**：代码高亮用的 highlight.js，语言自动检测；渲染前经过 DOMPurify 清洗，防止 XSS

---

## 第三部分：有效期与访问次数限制（1.5 分钟）

**念**：分享可以设有效期和访问上限，这是访问控制的核心。我创建一个只能访问 1 次的「阅后即焚」。

**操作**：
1. 输入一段敏感内容（示例：「会议室 WiFi 密码：ClipVault-2026」）
2. 访问次数选「1 次（阅后即焚）」→ 生成
3. 无痕窗口打开 —— **念**：第一次访问正常显示
4. 再刷新一次 —— **念**：内容已焚毁。达到上限后服务器**物理删除**了记录，不是标记失效
5. 回到创建页，再用「我的分享 → 焚毁」按钮演示手动销毁另一个分享

---

## 第四部分：端到端加密（1 分钟）

**念**：对于更敏感的内容，可以开启端到端加密。加密发生在浏览器里，服务器只存密文。

**操作**：
1. 隐私加密选「🔐 端到端加密」，输入内容，生成
2. **念**：注意链接里 # 号后面跟了一串密钥——URL 锚点不会发送到服务器，所以服务器永远拿不到密钥
3. 打开链接，内容正常解密显示
4. **念**：演示服务器端确实只有密文（可选：展示数据库查询 `select content from shares`）

---

## 第五部分：文件分享（1 分钟）

**念**：除了文本，还支持 100MB 以内的任意文件。

**操作**：
1. 切到「📎 文件」标签，拖拽一个文件进去（建议：一张图片 + 顺便展示一个 zip）
2. 生成分享，打开链接 —— 展示文件卡片（文件名、大小、剩余次数）
3. 点击下载，验证文件完好
4. **念**：存储名是服务端生成的随机 UUID，与用户文件名完全隔离，杜绝路径遍历攻击

---

## 第六部分：用户系统（1 分钟）

**念**：基础功能完全匿名，但注册登录后可以云端管理分享。

**操作**：
1. 点右上角「登录/注册」→ 注册一个账号
2. 登录后创建一个分享
3. **念**：「我的分享」现在显示的是云端列表，能看到每个分享的**访问统计**（被访问几次），并可以随时销毁
4. **念**：退出登录后匿名功能完全不受影响

---

## 第七部分：架构与收尾（1 分钟）

**念**：技术栈和部署简单说一下。

**操作**：
1. 打开 `http://服务器IP/docs` —— **念**：FastAPI 自动生成的交互式 API 文档
2. **念**：架构是 FastAPI + SQLAlchemy + SQLite，前端原生 JS 无框架；已部署在真实云服务器上，公网可访问，systemd 守护 + Nginx 反代；同时提供 Docker Compose 部署方案
3. **念**：安全设计包括：密码学随机短码、CSP 安全头、DOMPurify 防 XSS、PBKDF2 密码哈希、并发安全的原子计数。详细文档都在 GitHub 仓库里。
4. **念**：谢谢观看。
